## 3. 最大的进步：`convexDistance_eq_dual` 很重要，而且 statement 是对的

这次新增的

```lean
theorem convexDistance_eq_dual
```

证明：

[
d_A(x)
======

\sup_{\substack{w_i\ge0\|w|*2\le1}}
\inf*{y\in A}
\langle w,v(x,y)\rangle.
]

Lean statement 是：

```lean
convexDistance x A =
  sSup {r | ∃ w,
    ‖w‖ ≤ 1 ∧
    (∀ i, 0 ≤ w i) ∧
    r = ⨅ y : A, w ⬝ᵥ mismatchVector x y}
```



而 Pollard 的标准定义正是

[
d_w(x,y)=\sum_i w_i1_{{x_i\ne y_i}},
\qquad
D(x,A)=
\sup_{\substack{w_i\ge0\\sum_iw_i^2\le1}}
\inf_{y\in A} d_w(x,y),
]

并明确指出它等于 mismatch vectors 凸包中点的最小欧氏范数。([arXiv][1])

所以你现在 Lean 内部已经有了：

[
\boxed{
\text{weighted-Hamming definition}
==================================

\text{convex-hull distance definition}
}
]

这非常值钱。之前我评价“数学上等价，但 Lean 内部还没有 bridge theorem”，现在这个缺口已经真正补上了。

而且你这里注意到了一个很微妙但非常正确的 Lean 问题：

```lean
⨅ y : A, ...
```

必须用 **subtype**，不能写

```lean
⨅ y ∈ A, ...
```

因为在 `ℝ` 上后一种写法会让 `y ∉ A` 的 inner `iInf` 按 Lean 的 `sInf ∅ = 0` 处理，从而污染结果。你甚至给出了 (n=1) 的反例。

这个修正是很专业的，**这里的最终 theorem statement 是正确的。**

证明方向也对：

* dual (\le) primal：凸组合 + Cauchy–Schwarz；
* primal (\le) dual：取凸集离原点最近点 (z)，利用投影的 variational inequality，再令 (w=z/|z|)。

后面的实际 Lean proof 也确实按这个路线实现。 

Mathlib 当前文档里也能查到新增证明所依赖的关键 API，比如 `mem_convexHull_iff_exists_fintype`、`IsCompact.exists_infDist_eq_dist`、`real_inner_self_eq_norm_sq` 和你用的序列极限定理。([Lean Community][2])

## 4. 但 median 那三行现在需要改

这里是这版最主要的数学问题：

> `P(|f - med f| ≥ t) ≤ 4 exp(-t²/4)` — obtained from these implications using the two DIFFERENT sets `A₋ = {f ≤ m}` and `A₊ = {f ≥ m}`



**这句话对任意函数 (f) 来说不成立。**

这一点我也要更正一下我上一条回复里说得过快的地方：选两个 median sets 确实解决了“为什么两边各有至少 (1/2) 概率”的问题，但还差一个非常关键的步骤——

必须证明函数偏差能够强迫 convex distance 足够大。

例如需要某个 separation property：

[
f(x)\ge m+s
\quad\Longrightarrow\quad
d_{A_-}(x)\ge \frac{s}{L},
]

以及

[
f(x)\le m-s
\quad\Longrightarrow\quad
d_{A_+}(x)\ge \frac{s}{L}.
]

这通常来自 (f) 的某种 **convex-Lipschitz / certificate / bounded-sensitivity** 结构，而不是 median 本身。

有了这个额外 lemma，才能写：

[
P(f\ge m+s)
\le
P!\left(d_{A_-}\ge\frac{s}{L}\right)
\le
2e^{-s^2/(4L^2)},
]

另一边同理，最后 union bound：

[
\boxed{
P(|f-m|\ge s)
\le
4e^{-s^2/(4L^2)}.
}
]

只有当对应的 separation constant 是 (L=1) 时，才得到你注释里写的

[
4e^{-s^2/4}.
]

所以我建议把 2092–2095 那段改成类似：

> A genuine median-based two-sided concentration theorem additionally requires a hypothesis relating deviations of `f` from its median to convex distance from the lower/upper median sets.

不要直接宣称仅从这两个 set implications 就能得到那个公式。

## 5. `iInf_inner_convexHull` 我建议重构掉

你前面还有一个

```lean
theorem iInf_inner_convexHull
```

写的是

```lean
(⨅ z ∈ convexHull ℝ M, ...) = ⨅ v ∈ M, ...
```



你自己后面的 `convexDistance_eq_dual` docstring 已经正确指出：

> `⨅ y ∈ A, ...` 在 `ℝ` 上并不是真正的“对集合 A 取 infimum”。

所以这里多少有点内部风格冲突。

这个 theorem **不是假的**——你花了很多代码正确处理 Lean 那个特殊的 `sInf ∅ = 0` 语义——但它并不是我们数学上最想要的“linear functional 在集合与 convex hull 上的 inf 相等”的干净表示。

而且我全文搜索后，`iInf_inner_convexHull` 只出现了它自己的定义，**后面的 `convexDistance_eq_dual` 根本没用它。** 

我会建议直接把 90.1 改成 subtype 版本，例如思想上：

```lean
(⨅ z : convexHull ℝ M, w ⬝ᵥ z.1)
  =
(⨅ v : M, w ⬝ᵥ v.1)
```

并在需要时加 `M.Nonempty` / bounded-below 条件。

这样跟最终 dual theorem 的 subtype 风格完全统一，也可以删掉一大坨围绕 `iInf_prop_const_of_not` 和 `sInf ∅ = 0` 的技术处理。
