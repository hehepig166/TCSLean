仔细把定义、主定理和证明主干都过了一遍。**结论是：数学上，这份文件正确形式化了“有限、无向依赖图版本的非对称 Lovász Local Lemma（asymmetric LLL）”，证明结构也是对的。** 我没有发现会导致定理本身错误的数学漏洞。

不过有一个值得明确标出来的点：你自定义的 `IsDependencyGraph` 不是最常见的教科书/库式定义，而是一个非常贴合这份证明的等价/充分版本。最好以后补一个和标准 dependency graph 定义之间的 bridge theorem。

### 1. 主定理的陈述是标准 asymmetric LLL

你的最终 theorem 是

[
\mu(A_i)
\le
x_i\prod_{j\in\Gamma(i)}(1-x_j),
\qquad 0\le x_i<1
]

推出

[
\prod_i(1-x_i)
\le
\mu!\left(\bigcap_i A_i^c\right).
]

Lean 中正是：

```lean
theorem lovaszLocalLemma ...
    (hx₀ : ∀ i, 0 ≤ x i) (hx₁ : ∀ i, x i < 1)
    (hLLL : ∀ i,
      μ (A i) ≤
        ENNReal.ofReal
          (x i * ∏ j ∈ G.neighborFinset i, (1 - x j))) :
    ENNReal.ofReal (∏ i, (1 - x i))
      ≤ μ (⋂ i, (A i)ᶜ)
```

这就是经典 asymmetric LLL 的标准乘积形式。

而且你随后从 (x_i<1) 推出

[
\prod_i(1-x_i)>0
]

从而得到

[
0<\Pr\left[\bigcap_i A_i^c\right],
]

所以 existence form 也是正确的。

与已有形式化相比，AFP 中 Edmonds–Paulson 的 general LLL 也是同样的 (x_i\prod(1-x_j)) 条件和乘积下界，只是他们采用了更一般的 directed dependency graph / mutual independence 表述。([形式证明档案][1])

### 2. `bset` 的建模完全正确

你定义

```lean
def bset (A : ι → Set Ω) (S : Finset ι) : Set Ω :=
  ⋂ j ∈ S, (A j)ᶜ
```

所以 `bset A S` 就是“(S) 中所有 bad events 都没有发生”。

而

```lean
bset A Finset.univ = ⋂ i, (A i)ᶜ
```

也正确地把有限 `Finset` 归纳得到的结果连接到了最后 theorem 的全指标交集。

这一层没有问题。

### 3. 证明中最关键的 P1/P2 simultaneous induction 是正确的

这里其实是整份文件最值得检查的地方。

你的 strong induction 同时证明：

[
\tag{P1}
\prod_{j\in S}(1-x_j)
\le \Pr(B_S),
]

以及

[
\tag{P2}
\Pr(A_i\cap B_S)
\le x_i\Pr(B_S)
\qquad(i\notin S).
]

Lean 对应第 207–218 行。

这个 simultaneous induction 很重要，因为单独证明 P1 很容易偷偷循环使用 P2，而你的代码没有这个问题。

对于 P1，你取 (r\in S)，对 (S\setminus{r}) 使用 induction hypothesis 的 P2：

[
\Pr(A_r\cap B_{S\setminus{r}})
\le
x_r\Pr(B_{S\setminus{r}}),
]

然后利用

[
B_S=A_r^c\cap B_{S\setminus{r}}
]

得到

[
\Pr(B_S)
\ge
(1-x_r)\Pr(B_{S\setminus{r}}).
]

代码正是这一套。

这里没有 circular reasoning。

### 4. P2 中邻居/非邻居的拆分也正确

你对给定 (i\notin S)，定义

[
N=S\cap\Gamma(i),\qquad
M=S\setminus\Gamma(i).
]

即：

```lean
let N := S.filter (fun j => G.Adj i j)
let M := S.filter (fun j => ¬ G.Adj i j)
```



随后利用 dependency hypothesis 得到

[
A_i\perp B_M,
]

于是

[
\Pr(A_i\cap B_M)
================

\Pr(A_i)\Pr(B_M).
]

然后由于 (B_S\subseteq B_M)，

[
\Pr(A_i\cap B_S)
\le
\Pr(A_i\cap B_M).
]

这些方向都是对的。 

Mathlib 当前 `IndepSet` 的语义也与你这里的使用一致；对于可测集合，它可以通过交集测度等于乘积来使用，所以 `indepSet_iff_measure_inter_eq_mul` 这一步数学上没有偷换概念。([LeanProver社区][2])

### 5. 一个很容易写反的不等式，你这里写对了

这是我特别检查的一处。

因为

[
N\subseteq\Gamma(i)
]

且

[
0<1-x_j\le1,
]

所以给乘积增加更多因子会让它**变小**：

[
\prod_{j\in\Gamma(i)}(1-x_j)
\le
\prod_{j\in N}(1-x_j).
]

你的代码正是

```lean
have hofN :
    ENNReal.ofReal
      (∏ j ∈ G.neighborFinset i, (1 - x j))
    ≤ ENNReal.ofReal
      (∏ j ∈ N, (1 - x j))
```



这个方向完全正确，而且当前 mathlib 的 `Finset.prod_le_prod_of_subset_of_le_one'` 本身就是为这种“subset + extra factors ≤ 1”情形设计的。([LeanProver社区][3])

这是 LLL 手写证明里一个挺常见的 sign/direction bug，你这里没犯。

### 6. `prob_bset_inter_prod` 也是正确补上了经典条件概率链

你的 lemma 本质证明

[
\Pr(B_{N\cup M})
\ge
\left(\prod_{j\in N}(1-x_j)\right)\Pr(B_M).
]



然后在 P2 中组合

[
\begin{aligned}
\Pr(A_i\cap B_S)
&\le \Pr(A_i)\Pr(B_M)\
&\le x_i
\prod_{j\in\Gamma(i)}(1-x_j)
\Pr(B_M)\
&\le x_i
\prod_{j\in N}(1-x_j)
\Pr(B_M)\
&\le x_i\Pr(B_{N\cup M})\
&=x_i\Pr(B_S).
\end{aligned}
]

代码第 305–341 行与这条数学推导是一一对应的。

所以 proof architecture 本身是很干净的。

## 唯一真正值得加星号的地方：`IsDependencyGraph`

你定义的是：

```lean
def IsDependencyGraph (G : SimpleGraph ι) (A : ι → Set Ω) : Prop :=
  ∀ i (S : Finset ι),
    i ∉ S →
    (∀ j ∈ S, ¬ G.Adj i j) →
    IndepSet (A i) (bset A S) μ
```



也就是说，对于任意由 (i) 的非邻居组成的 (S)，直接要求

[
A_i\perp \bigcap_{j\in S}A_j^c.
]

这对你的证明**绝对足够**，所以不会影响 `lovaszLocalLemma` 的正确性。

但教科书里更常见的 dependency graph 说法是：

> (A_i) 与所有非邻居事件 (A_j) 所生成的 σ-algebra 独立，

或者使用某种 mutual-independence formulation。AFP 的形式化也是沿这种方向定义 dependency relation 的。([形式证明档案][1])

在你现在的**有限、可测、概率空间**设定下，这两种描述在数学上可以通过 π–λ / generated σ-algebra argument 联系起来：所有

[
\bigcap_{j\in S}A_j^c
]

形成的系统生成的正是非邻居事件生成的 σ-algebra。所以你的条件并不是一个“奇怪的新 LLL 条件”。

但是——**这个 equivalence/bridge 目前没有在该 Lean 文件中形式化出来。**

因此如果目标是“证明一个 mathematically correct LLL”，现在已经够了。

如果目标是“做一个 mathlib-quality、别人看到 `IsDependencyGraph` 就能马上知道和标准定义完全对接的 LLL API”，我会建议再补一个标准 dependency graph 定义以及类似

```lean
standardDependencyGraph_isDependencyGraph :
  StandardDependencyGraph G A →
  IsDependencyGraph G A
```

的 bridge theorem。甚至如果方便，可以证明 iff。

这会是我认为目前最值得补的东西。

### 另外几个不是错误、只是 generality 限制的地方

你的版本限定 `[Fintype ι]`，所以形式化的是**finite LLL**，不是 infinite LLL；这正是经典组合数学里最常用的版本，并无问题。图用 `SimpleGraph`，因此是无向 simple dependency graph；也完全是标准版本，只是不如 directed dependency graph 那么一般。

另外，现在 independence 用的是等式意义上的真正 independence，因此这是普通 LLL，不是更弱假设的 **lopsided LLL**。以后如果想推广，P2 的证明实际提示了一个很自然的方向：非邻居处只要求适当的负相关/条件概率上界即可。

还有一点 API 层面的 polish：`lovaszLocalLemma_pos` 得到的是

```lean
0 < μ (⋂ i, (A i)ᶜ)
```

而不是直接给

```lean
∃ ω, ∀ i, ω ∉ A i
```

但正测度当然蕴含集合非空，所以数学上完全够。若应用端经常最终需要一个 witness，可以再加一个存在性 corollary。
